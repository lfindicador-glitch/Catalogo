# Catálogo Corte e Cria Decor (orçamento pelo WhatsApp)

Não precisa de banco de dados, login nem pagamento. É só um site com os arquivos desta pasta.

## Publicar (grátis, uns 10 minutos)
1. Crie conta em github.com e clique em **New repository**. Nome: `catalogo`. Marque **Public** e **Add a README**.
2. **Add file → Upload files:** arraste TODO o conteúdo desta pasta (index.html, orcamento.html, orcamento.js, orcamento.css, app.js, pdf.js, style.css, config.js, produtos.js, as pastas `fotos` e `assets`). Clique em **Commit changes**.
3. **Settings → Pages:** Branch `main`, pasta `/ (root)` → Save.
4. Em 1 ou 2 minutos o endereço aparece: `https://SEU-USUARIO.github.io/catalogo/`. Cole esse link na bio do Instagram.

## Como o cliente usa
Abre o link → escolhe o produto → cor, quantidade e, se quiser, o nome para gravar → **Adicionar ao orçamento** → informa o nome → **Solicitar orçamento pelo WhatsApp**. O WhatsApp abre já com a mensagem pronta para o número da loja: produtos, cor, quantidade, personalização, medidas, observações e um **link do pedido**. Quando você toca no link, abre uma página com o pedido completo e **as fotos de cada item**, com botão para baixar o PDF. Na mesma tela ele baixa o **PDF do orçamento com as fotos** (e, no celular, pode compartilhar o PDF direto na conversa).

## Mudar depois
- Número, Instagram, cores e mensagem final: arquivo `config.js` (clique no lápis no GitHub, edite e faça Commit).
- Produtos e medidas: arquivo `produtos.js`; fotos: pasta `fotos` (nome do arquivo = código do produto). Para incluir produtos novos, me envie os PDFs que eu devolvo os arquivos atualizados.
- O endereço nunca muda. Se aparecer a versão antiga, atualize a página (Ctrl+F5).

## Limites
- O WhatsApp não permite anexar fotos automaticamente; por isso as fotos aparecem na página do link do pedido (e no PDF).
- O link do pedido só funciona depois que o site estiver publicado no GitHub Pages (endereço público).
- O orçamento não vai por mensagem direta do Instagram (o Instagram não permite). O link na bio leva ao catálogo e o pedido chega no WhatsApp.
- Não há preços: tudo é orçamento.
